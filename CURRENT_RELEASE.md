# Norm 0.55.10r26 — Generic Vision Media

Latest public source revision: v0.55.10r26, built on r25 (2026-10-18).

Extends the built-in vision_parse plugin with YuNet/SFace face observations and embeddings, UUIDs, full-timeline two-pass scene boundaries (minimum 30 seconds), category tags, and read-only person merge proposals. Differing manual aliases cannot merge automatically; identical aliases still require strong visual evidence. No changes to N1/N2 architecture.
