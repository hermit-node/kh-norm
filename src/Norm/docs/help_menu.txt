Norm commands

help or /help
  Show this file.

Model
  /switch-model
      List Ollama models available to Norm and mark the current session model.
  /switch-model N
      Switch this Norm session to numbered model N.
  /switch-model MODEL
      Switch this Norm session to an exact installed Ollama model name.
      The candidate is probed before any live client changes. A failed probe leaves
      the current model unchanged. Norm always boots/restarts on model "norm".

Status / context
  /about
      Show Norm version, runtime, package, and plugin summary.
  /status
      Show local/runtime queue state.
  /status/busy
      Show authoritative runtime busy state.
  /network-map [--json]
      Passive Tailscale inventory plus explicitly allowlisted probes.
  /queue [N]
      Show queued GUI prompts plus any active/parked scheduled maintenance job.
  /queue-full
      Show full prompts, scheduled maintenance, and parked/uncertain delivery state.

Threads / input
  /new [name]
      Start a fresh conversation thread, optionally with a title.
  /thread-list
      List active conversation threads; * marks the current thread.
  /thread-resume NAME
      Switch to a thread by exact title, unique prefix, ID, or ID prefix.
  /multi
      Start multiline prompt entry; finish with ::send or cancel with ::cancel.
  /inject-context [--task ID] TEXT
      Save context for the current task tree without creating a new task.
  /repeat-submission
      Requeue the last submitted prompt verbatim.
  /repeat-answer
      Redisplay the last completed Norm answer verbatim.

Task control
  /suppress-task
      Park the active task tree, oldest queued task tree, or active scheduled maintenance when no user task is ahead of it.
  /resume-task [N]
      List suppressed user tasks, or resume an index/task-id/prefix directly.
  /resume-task maintenance
      Explicitly resume scheduled maintenance that was suppressed or parked for attention.
  /flush-suppressed
      Permanently delete suppressed tasks and parked delivery records.

Files / backup
  /delete-list
      List reversible soft-deleted files.
  /restore-delete ID
      Restore one deletion ID; use all for every non-conflicting item.
  /delete-files
      Permanently purge reversible trash now.
  /backup
      Create a portable installer/source backup.
  /backup full
      Create a sensitive full backup with private state and PostgreSQL.

Memory maintenance
  Scheduled regular maintenance distills recent history into a tight working-memory snapshot; detailed reconstructable history remains in task_history.
  A deterministic output-budget failure parks scheduled maintenance instead of automatically retrying forever.

  /memory-condense
      Compact/replay-validate only the recent memory window (default 14 days).
  /memory-condense -deep
      Run one bounded older-history compaction/validation pass without hierarchical merging.
  /memory-condense -full
      Sweep full history: sample 12 per 200 dated rows, then merge neighboring rows conservatively.

Runtime control
  /mute ollama
  /unmute ollama
      Hide/show Ollama thinking and answer output; work continues.
  /mute norm
  /unmute norm
      Hide/show Norm runtime messages; work continues.
  /stop ollama
      Cancel active Ollama generation.
  /shutdown ollama
      Unload the active model and gracefully stop Ollama.
  /stop norm
      Pause sending queued console prompts after the current one.
  /start norm
      Resume sending queued console prompts.
  /stop-all
      Finish the current step, snapshot recovery state, then stop Norm/Ollama.
  /stop-all now
      Emergency checkpoint/snapshot and stop Norm/Ollama now.
  /shutdown norm
      Gracefully stop Norm after checkpointing current work.
  /shutdown norm now
      Cancel active work and stop Norm promptly.
  /shutdown
      GUI alias for graceful Norm shutdown.
  /shutdown now
      GUI alias for immediate Norm shutdown.
