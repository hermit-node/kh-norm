# Norm 0.55.1 implementation and open-work audit (2026-10-08)

This audit compares the extracted 0.55.0 portable-source baseline to 0.55.1. Source presence and isolated tests are not proof that the installed Windows build is running the changes.

| Feature / fix | Package status | Qualification |
| --- | --- | --- |
| Context injection auto-retirement, opt-in checkbox, audit log and manual controls | Added 0.55.1 | PostgreSQL schema + step-verifier path; live integration not run |
| Active voice styles in queued N2 worker | Added 0.55.1 | Loaded from hash-verified active prompt; live Ollama comparison pending |
| Cockney style strength | Enhanced 0.55.1 | `/voice-tune NAME --preset cockney` followed by activation; A/B test available; no claim of proven accent adoption |
| Corpus voice/persona synthesis and help/slash voice controls | Present | Existing capabilities retained; source-only check |
| Lesson-model/code-memory and interactive topology | Present from 0.55.0 | Does not train/promote weights; plugin-specific runtime dependencies need live test |
| `/help plugins` and `/help plug-ins`; plugin help.txt | Present | Source and help tests |
| OCR-first PDFs/images, grayscale coverage, selective vision, image masking | Present | Tesseract host executable not bundled; real-model accuracy not verified |
| Resource runway grace and suppression tombstones | Present from 0.54.3 | No live stress test this round |
| Installer catalog SHA/version synchronization | Present | Metadata verified; Windows installation not run |
| Installer compatibility with legacy 1.6.x | Unconfirmed | The supplied 0.55.0/0.55.1 source manifest has no `build_script`, and source excludes `tools/build_norm.py`; older 1.6.x installer validation expects those keys. Installer 2.0.0 is external to this ZIP. |
| Arbitrary duplicate tool mutation detection | Not implemented | Separate idempotence guard remains backlog |
| Full end-to-end Windows + PostgreSQL + Redis + Ollama validation | Not completed here | Needs a live local smoke test |
| Voice effect in existing already-running tasks | Not guaranteed | Fresh worker slices load active voice; old in-flight prompts can retain prior context |
| Learning-model automatic weight training/promotion | Not implemented | Explicitly disabled, per prior design |

Use `docs/RELEASE_NOTES.md` for the historical ledger and `docs/FUTURE_IMPLEMENTATION_NOTES.md` for the remaining backlog. Do not delete, overwrite or auto-rewrite the user's existing private `state/voice_profiles` data during installation.
