Norm console — quick reference

/help                    This compact command index
/help plugins            List installed plugins with a help.txt manual
/help voice-profiler     Voice training, selection, and inspection commands
/help vision-parse       PDF/image OCR and selective-vision commands
/help lesson-model       Lessons, source-code memory, README and topology tools

/queue [N]               Queue snapshot
/queue-full              Full queue and parked records
/status                  Runtime + queue status
/switch-model [N|NAME]   List or switch the current model
/new [name]              Start a new conversation
/thread-list             List conversation threads
/thread-resume NAME      Resume a conversation thread
/inject-context TEXT     Add context (auto-retire after verification; -persist to retain)
/injections [--manage]   List and checkbox-retire fulfilled injections
/injection-retire ID      Stop repeating an injection; preserves history
/injection-restore ID     Reactivate a retired injection
/suppress-task           Suppress the active/next task
/resume-task [N]         Resume a suppressed task
/failed                  Recent failed tasks
/resume-failed N         Resume failed task
/backup                  Portable source backup
/about                   Version and plugin summary
/stop-all                Finish current step and stop Norm/Ollama
/exit                    Close this prompt console without stopping Norm

Use /help plugins for plugin commands; the remaining legacy controls
are documented in docs/help_full.txt.
Trash: /soft-delete "PATH", /delete-list, /restore-delete ID, /delete-files.
