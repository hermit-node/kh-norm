Vision Parse (vision_parse) — direct PDF/image reader commands

Run locally in Norm Prompt; these commands do NOT create queued N2 tasks.
Supports PDF, PNG, JPG/JPEG, WebP, BMP and multi-frame TIFF.
The user-selected file must be inside an authorized read root.

/vision
    Quick reader command index.
/vision-status
    Verify the installed plugin identity; show local Tesseract availability.
/vision-parse "PATH" [--page N | --start N --end N]
              [--mode hybrid|text|vision] [--focus "INSTRUCTION"]
              [--suspect "EXCERPT"] [--full|--json]
    Read up to 10 pages/frames per call, returning coverage/OCR/vision decisions
    and a bounded preview of extracted text. Defaults to hybrid.
    --page N reads exactly one page. --start N continues a multi-page read.
    --full prints unabridged extracted text; --json displays the full result.
    Quote Windows paths when they contain spaces.
/vision-read "PATH" [...]
    Alias for /vision-parse.
/vision-text "PATH" [--page N | --start N --end N] [--full]
    Force native PDF text or conventional raster OCR, with NO vision calls.
/vision-force "PATH" [--page N | --start N --end N] [--focus "..."]
    Force vision even when extraction appears trustworthy.
/vision-recheck "PATH" "SUSPECT EXCERPT" [--page N] [--full]
    Hybrid read: visually recheck this suspicious passage/line without
    unnecessarily rerunning vision over unaffected content.

How hybrid works:
    Native PDFs: compare grayscale visible ink to extracted text geometry.
    Clean pages skip Ollama. Scans/images: Tesseract OCR first, then send
    only unexplained/low-confidence regions to Ollama vision. Model results
    include coverage, crop provenance and anomalies; OCR may still be wrong.

Prerequisites: PyMuPDF and Pillow (Python), optionally pytesseract and the
separate Tesseract binary. Hybrid can fall back to vision without Tesseract.
To authorize an additional source folder, configure:
    [file_access_overrides]
    vision_parse.read_add = D:\\Some\\DocumentFolder
Do not bypass a rejected read path using another tool.
