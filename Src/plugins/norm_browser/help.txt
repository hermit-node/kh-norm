Norm Browser Cooperation
- Inspect/approve HTTPS sites from the Shared Browser left actions rail.
- Ask Norm: natural-language browser tasks are submitted to the existing Norm prompt ingress.
- Export: select conversation turns, choose PDF / Markdown / ZIP / JSON and formatting.
- Page script tools: browser_script_execute, browser_script_register, browser_script_remove.
- Session defaults to the existing shared Qt profile; Playwright remains a separate optional backend.

Export attachment fidelity: resolves `file_...` and multimodal `sediment://file_...` references using the logged-in ChatGPT tab. ReportLab PDF and ZIP are generated locally. Missing attachments block UI export by default; user may explicitly permit partial export; all failures are reported.
