Norm lesson/code-memory plugin

Purpose
  Capture operator-approved reusable lessons and build versioned code memories from source ZIPs.
  Code scans can retain the complete source ZIP, store dense machine memory in PostgreSQL, write a human README, and emit an interactive topology map.

Lesson workflow
  propose_lesson(...)              Create a candidate only.
  approve_lesson(...)              Requires explicit user/operator approval.
  reject_lesson(...)               Reject candidate.
  set_training_eligibility(...)    Control whether an approved lesson may enter future training data.
  prepare_model_build(...)         Freeze a dated candidate manifest; training/promotion remain disabled in this skeleton.

Code-memory workflow
  code_memory_scan_zip(...)        Inventory and retain an immutable wholesale ZIP snapshot.
  code_memory_next(...)            Return one bounded source chunk in runtime-priority order.
  code_memory_save_analysis(...)   Save Norm's dense structured understanding.
  code_memory_persist_postgres(...) Persist the raw structured snapshot in the configured Norm runtime schema.
  code_memory_write_readme(...)    Write the separate human-facing README.
  code_map_save_semantics(...)     Add semantic roles/clusters/data meanings.
  code_map_write_interactive(...)  Emit standalone interactive topology HTML.

Safety / invariants
  Candidate creation is not approval. Never call approve_lesson merely because propose_lesson succeeded.
  Mutable facts belong in evidence/code memory, not training weights.
  Training and norm:latest promotion are intentionally disabled until a reviewed backend and regression gate are integrated.
  User source ZIPs are copied; the original input ZIP is not moved, renamed, or deleted.
