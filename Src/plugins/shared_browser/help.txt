Norm Shared Browser r11:
 browser_shared_status - visible, manual_control, loading, URL
 browser_shared_show - reveal page; preserve controller
 browser_shared_hide - hide page; preserve controller
 browser_shared_take_control - human owns page; Norm operations paused
 browser_shared_release - Norm owns page; no automatic hide
 browser_shared_open/dom/bs_select/messages/scroll/click/type - page actions
 browser_shared_archive_loaded - loaded chat turns to JSONL
 browser_shared_pdf - PDF from nonempty verified-source JSONL; partial status
 Paths: configured Documents workspace/web/shared_browser/exports
 Double-click C:\Norm\Show Shared Browser.cmd to reveal the
 existing browser from Windows Explorer, without spawning another.

browser_shared_visual_pdf(name="") - asynchronous stitched screenshot PDF; optional name
browser_shared_visual_status - poll frames, output paths, capture uncertainty
browser_shared_visual_cancel - stop in-progress capture without altering saved PDFs

browser_shared_visual_title_context(last_user=3) - recent user turns for choosing PDF name

Shared Browser PDF formats and Norm Prompt direct shortcuts (0.55.10r6):
  /pdf                                   List supported PDF shortcuts
  /pdf-chat "SOURCE.pdf" [--name "TITLE"] [--output "FILE.pdf"] [--include-original]
  /pdf-dialogue "SOURCE.pdf"             Alias for /pdf-chat (rich native-vector PDF)
  /pdf-name "SOURCE.pdf"                 See original dates/user turns for choosing a title
  /pdf-verify "SOURCE.pdf" "DIALOGUE.pdf" Compare source words, original images and bookmarks
  /pdf-text "ARCHIVE"                    Text PDF from existing archived chat JSONL
  /pdf-visual ["TITLE"]                  Start scrolling screenshot capture in shared browser
  /pdf-status                             Check visual PDF capture status
  /pdf-cleanup ["FOLDER"] [--older-hours 24] [--execute]
                                           Dry-run by default; only stale *.partial-PID.pdf files
  /help shared-browser                    Show this manual

Native tool: browser_shared_pdf_export(format="text|visual|dialogue", name="", source="", output="", include_original=False)
Native tools: browser_shared_pdf_title_context(source), browser_shared_pdf_verify(source,output), browser_shared_pdf_cleanup(directory="",dry_run=True,older_than_hours=24)

Naming convention: "{title} - Rich Dialogue.pdf" in source folder unless --output is provided.
A separate .verification.json records the source and output SHA256 and PDF fidelity checks.
Never overwrites the source, existing output, completed reports, or other plugins/settings.
Rich dialogue requires existing original ChatGPT Exporter PDF; the visual capture is a separate live-browser workflow.
