Norm Installer Kit 1.4.15 / Norm 0.53.7

Norm 0.53.7 large-source/task-storage changes:
- read_file no longer rejects a source because the whole file exceeds a tiny size cap.
- source size is separate from processing buffer (24 MiB), model-facing tool result (384 KiB), internal note chunk (5 MiB), per-pass processing allowance (3 GiB), and task-owned storage ceiling (54 GiB).
- reaching the 3 GiB pass or 54 GiB task-storage ceiling checkpoints and parks the same task for manual resume.
- task-local reproducible image-analysis derivatives are cleaned after verified completion; compact lineage plus internal notes survive in workspace/.norm-task-retention.
- human-facing final replies are capped at 384 KiB while the full durable summary remains in PostgreSQL and oversized complete text is spilled to workspace/large-responses.

Installer 1.4.15 retains 1.4.13+ dependency-persistence and runtime-window-centered package-resolution dialogs, the reusable PyInstaller cache behavior, and 0.53.6 recovery/provenance/interjection fixes.
