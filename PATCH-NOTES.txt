Norm Installer 1.4.2 / Norm 0.52.6

Runtime launch/HTTP reliability release.

Norm 0.52.6 changes:
- Core service is launched detached from operator consoles and always with --service.
- Run-Norm.bat will not start a duplicate norm.exe merely because 12543/8766 are temporarily offline.
- GUI fallback auto-start also uses --service.
- Windows service mode adds a native SetConsoleCtrlHandler guard in addition to Python signal handlers.
- GUI DB3 prompt dispatch catches bootstrap/HTTP races instead of letting the dispatcher thread die.
- A later queued prompt can revive a dead dispatcher thread while preserving the DB3 queue.

Installer 1.4.2 keeps the 1.4.1 auto-source behavior: the installer discovers the newest valid Norm source ZIP beside itself rather than being bound to one hardcoded ZIP.
