Norm Installer Kit 1.4.16 / Norm 0.53.8

Same-version launcher presentation refresh:
- automatic norm.exe --service startup is now fully headless (CREATE_NO_WINDOW + hidden startup info), eliminating the inert service console while keeping the same shutdown-owned process lifecycle.
- Run-Norm.bat prefers a dedicated Windows Terminal window for Norm Runtime when wt.exe is available; Prompt and Replies are unchanged and Runtime falls back to the classic console if needed.
- this is intentionally still Norm 0.53.8 / Installer Kit 1.4.16.

Norm 0.53.8 Ingrained Details / unresolved-bits changes:
- preserves the full mixed user turn while planning from a separate primary task request.
- routes confident side details directly to final durable homes and stores only genuinely unplaced details in PostgreSQL unresolved_bits.
- records bounded unresolved_bit_trials against later tasks; successful promotion removes temporary rows, while broad repeated irrelevance can prune them.
- includes unresolved state/trial aggregates in background-memory condensation.
- carries DB3 prompt_id into durable task provenance so /queue can report the matched task and current step.

Norm 0.53.8 large-source/task-storage changes:
- read_file no longer rejects a source because the whole file exceeds a tiny size cap.
- source size is separate from processing buffer (24 MiB), model-facing tool result (384 KiB), internal note chunk (5 MiB), per-pass processing allowance (3 GiB), and task-owned storage ceiling (54 GiB).
- reaching the 3 GiB pass or 54 GiB task-storage ceiling checkpoints and parks the same task for manual resume.
- task-local reproducible image-analysis derivatives are cleaned after verified completion; compact lineage plus internal notes survive in workspace/.norm-task-retention.
- human-facing final replies are capped at 384 KiB while the full durable summary remains in PostgreSQL and oversized complete text is spilled to workspace/large-responses.

Installer 1.4.16 retains 1.4.13+ dependency-persistence and runtime-window-centered package-resolution dialogs, the reusable PyInstaller cache behavior, and 0.53.6 recovery/provenance/interjection fixes.
